# Setting Up Your Environment

A working setup should be reliable, simple, and easy to share with teammates.

## Core tools

- A code editor (VS Code is a common choice)
- Git
- A GitHub account
- Language/runtime tools required by your chosen project (for example Python or Node.js)

## Basic setup steps

1. Install Git and your editor.
2. Configure Git identity:

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

3. Generate or use an existing GitHub SSH key (optional but recommended).
4. Clone project repositories and test that they run.

## Beginner-friendly entry point

If this is your first technical project, start with a documentation update or small bug fix. This lets you learn the workflow before building larger features.

## Troubleshooting checklist

- Confirm tools are installed (`git --version`, `python --version`, or `node --version`).
- Ask a teammate to review setup errors.
- Document fixes so future members can avoid the same issue.
