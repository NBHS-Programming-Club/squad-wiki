# Using Git and GitHub

Git tracks changes locally. GitHub helps your team review, discuss, and merge those changes.

## Essential workflow

1. Create a branch for your work.
2. Commit changes in small logical steps.
3. Push your branch and open a pull request.
4. Request review and respond to feedback.
5. Merge when checks pass and reviewers approve.

## Useful commands

```bash
git checkout -b feature/my-update
git add .
git commit -m "Add project proposal template"
git push -u origin feature/my-update
```

## Good habits

- Write clear commit messages.
- Keep pull requests focused.
- Pull updates from `main` regularly.
- Never commit secrets or private credentials.
