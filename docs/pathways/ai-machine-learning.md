# AI & Machine Learning

## What this field involves

AI and ML projects use data to make predictions, decisions, or intelligent responses. Work can include data cleaning, model training, computer vision, and AI-powered applications.

## What members can build

- Classifiers for images or text
- Recommendation prototypes
- Chat interfaces backed by AI services
- Computer vision tools
- Data dashboards with ML insights

## Suggested technologies and tools

- Python
- NumPy, pandas, scikit-learn
- Jupyter notebooks
- OpenCV
- Lightweight model APIs for experimentation

## Prerequisites and beginner entry point

- Basic Python and functions
- Introductory statistics concepts (mean, variance, accuracy)
- Entry point: build a simple classifier from a clean dataset

## Progression

- **Beginner:** data cleaning, train/test split, simple classification
- **Intermediate:** feature engineering, model comparison, evaluation metrics
- **Advanced:** computer vision pipelines, deployment, model monitoring

## Project ideas

1. Handwritten digit classifier
2. Movie recommendation prototype
3. Spam message detector
4. Basic face or object detector
5. Study-helper Q&A assistant

## Suggested first project

Start with a **spam message detector** using scikit-learn. It is small, testable, and teaches core ML workflow.

## Testing and demonstration

- Split data into train/validation/test sets.
- Report precision, recall, and accuracy.
- Demo with new sample inputs and explain model limits.
