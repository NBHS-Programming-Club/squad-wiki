# Programming Squad Wiki

Welcome to the Programming Squad technical knowledge base. This wiki helps members learn practical skills by building real projects, documenting what they learned, and presenting the results.

## Learn by building

Our core principle is simple: **pick a project first, then learn the technologies needed to complete it**. You do not need to follow a rigid curriculum or master every tool.

## Project lifecycle

A typical squad project moves through this cycle:

**Choose → Plan → Learn → Build → Test → Present**

- **Choose:** pick a meaningful idea.
- **Plan:** define an MVP and milestones.
- **Learn:** focus only on skills required for your project.
- **Build:** implement features iteratively using Git.
- **Test:** verify behavior and collect feedback.
- **Present:** document outcomes and demo what you built.

For the full team workflow, see the [Squad Handbook](handbook/squad-workflow.md).
