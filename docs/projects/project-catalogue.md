# Project Catalogue

This catalogue helps members choose projects by interest and challenge level. These are **suggestions, not compulsory assignments**.

## How to choose a project

1. Pick a problem you care about.
2. Define a realistic MVP.
3. Select only technologies needed for that MVP.
4. Confirm your team can test and demonstrate the final result.

## Suggested workflow

Use the squad process in [Workflow and Collaboration](../handbook/squad-workflow.md):

1. Propose idea
2. Agree MVP
3. Plan milestones
4. Learn and prototype
5. Build iteratively
6. Test and improve
7. Document and present
