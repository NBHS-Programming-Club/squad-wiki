2. Set up your workspace

Install the shared tools first, then the tools for this pathway. If you are using a school computer, ask before installing software.

Shared tools

ToolPurposeCheck
VS CodeWrite and inspect source files.Open it and create a plain text file.
GitRecord changes and move between versions.git --version
GitHub accountStore code and share work.Sign in at github.com.
TerminalRun programs and tools directly.echo hello

ML & AI tools

ToolPurposeCheck
Python 3The language used throughout this pathway.python --version
Virtual environmentKeeps each project's packages separate.python -m venv .venv
Core packagesData handling, plots, and models.pip list
Tool problem? Record the operating system, tool version, command you ran, and complete error message. Avoid copying a random command from a forum until you understand what it changes.

Create a project folder

mkdir programming-squad
cd programming-squad
mkdir exercises final-project
git init
python -m venv .venv

Use a separate repository for your final project when you are ready. Keep the repository name short, use a README, and never commit passwords, API keys, or private personal data.
