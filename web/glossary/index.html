7. Glossary and next steps

TermMeaning in this guide
AlgorithmA precise sequence of steps for solving a class of problems.
APIA defined way for one program or service to request data or actions from another.
BugObserved behaviour that does not match the intended behaviour.
CommitA named, recorded change in a Git repository.
DependencyCode or software your project relies on to run.
IterationA small cycle of building, checking, learning, and improving.
RepositoryA project folder tracked by Git, often shared through GitHub.
ScopeThe boundary of what a project will and will not include.
After the capstone: publish a short retrospective, choose one next technical topic, and improve the project in a small follow-up issue. A finished project is a foundation for the next one, not a final test of whether you belong.
